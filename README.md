# 🌍 Travel Destination Dashboard (Excel)

An interactive Microsoft Excel dashboard for analyzing travel destinations, distances, travel duration, and transportation modes between major cities. This project demonstrates how Excel can be used to transform raw travel data into meaningful insights using Pivot Tables, Pivot Charts, Slicers, and Dashboard visualizations.

---

## 📌 Project Overview

The Travel Destination Dashboard provides a visual representation of travel information between multiple cities. It enables users to explore travel routes, compare transportation methods, analyze travel distances, and identify efficient travel options.

The dashboard is designed for learning data analysis and dashboard creation using Microsoft Excel.
